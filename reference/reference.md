@观澜 腾讯音乐人完整注册入驻教程（2026最新）
 
一、入驻前准备材料
 
1. 实名证件：大陆身份证（需人脸核验）；港澳台/海外可用通行证、护照

2. 音乐人资料：歌手艺名、头像、曲风、个人简介

3. 音乐作品：至少1首原创/改编歌曲，格式MP3/WAV，单文件≤200M

4. 手机号：用于账号绑定、接收审核通知
 
二、两种注册入口（手机小程序/电脑网页）
 
方式1：微信小程序（手机快速注册，推荐新手）
 
 
 
1. 微信顶部搜索 腾讯音乐人 小程序，点击进入

2. 微信授权登录，下滑找到 立即入驻

3. 选择入驻类型：

- 普通音乐人：绝大多数创作者、翻唱/原创歌手

- 校园入驻：仅限在校学生，可享校园扶持计划

4. 输入你的音乐人艺名：

- 搜到同名歌手页 → 选择认领音乐人

- 无匹配结果 → 点击我要创建新建歌手主页

5. 完善音乐人主页信息：头像、曲风、地区、歌手简介

6. 实名认证：填写身份证信息，完成人脸识别核验

7. 上传一首原创/改编歌曲，填写歌名、词曲、版权信息提交审核

8. 等待审核通过，即成功注册腾讯音乐人
 
方式2：电脑网页端（适合机构、词曲作者、批量发歌）
 
 
 
1. 浏览器打开官网：https://y.tencentmusic.com

2. QQ/微信扫码登录，点击首页立即入驻

3. 身份选择：个人音乐人 / 机构入驻（公司、唱片公司）

4. 新建音乐人 / 认领已有歌手账号，填写艺人资料

5. 完成实名+人脸核验

6. 上传歌曲、填写版权信息提交审核
 
网页端支持词曲作者、唱片公司机构入驻，小程序仅支持个人音乐人
 
三、审核规则&时效
 
1. 资料审核：实名信息一般几小时内出结果

2. 歌曲审核：原创作品常规24小时内，高峰期最长72小时

3. 审核不通过原因常见：

- 歌曲非原创、无完整版权

- 人脸实名信息不一致

- 艺名重复、违规敏感名称

- 音频音质破损、时长过短
 
四、入驻成功权益
 
- 作品同步上架 QQ音乐、酷狗、酷我、全民K歌

- 作品播放收益、版权分成、词曲结算

- 音乐人官方主页、专属音乐人标识、平台流量扶持

- 参与官方音乐企划、校园音乐人计划、词曲征集活动
 
补充小贴士
 
1. 翻唱入驻：需要获得原曲版权授权，否则审核会驳回

2. 未成年人：需户口本+监护人授权材料才能入驻

3. 入驻后艺名、头像、简介均可后台修改，无需重新审核
